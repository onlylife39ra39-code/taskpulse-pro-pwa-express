# TaskPulse Pro - Modern ToDo & Workflow PWA

タスクの追加・編集・ステータス管理（未完了/進行中/完了）・優先度設定・タグフィルター機能、Express REST API、ローカルストレージおよびPWAオフラインキャッシュ機能に対応したプログラマブルWebアプリケーション。

## 主な特徴
- 🎨 **モダンなUI/UX**: Dark Theme, Glassmorphism design system & Dynamic Status Progress bar.
- ⚡ **オフライン対応 (PWA)**: Service Worker による静的ファイルのキャッシュ & オフライン時でもローカルストレージでシームレス操作。
- 🏷️ **柔軟な分類機能**: 優先度 (High/Medium/Low)、ステータス (未完了/進行中/完了)、動的ハッシュタグでのマルチフィルター。
- 🚀 **Express REST API Backend**: Node.js + Express による高速かつ拡張容易なバックエンドAPI。

## ローカル実行手順

```bash
# 依存パッケージのインストール
npm install

# サーバーの起動
npm start
```

ブラウザで `http://localhost:3000` にアクセスしてください。
